# Younes Chibane — Portfolio

Static portfolio built with HTML5, CSS3 and vanilla JavaScript. Hosted on GitHub Pages: https://youneschibane.github.io/

## Update contact details
Edit the `CONFIG` block at the top of `script.js` (email, LinkedIn). Empty values stay hidden.

## Add a project
Copy an `<article class="project">` block in `index.html` (see the comment in the Projects section).

## Files
`index.html` · `style.css` · `script.js` · `favicon.svg` · `og-image.png` · `robots.txt` · `sitemap.xml`
