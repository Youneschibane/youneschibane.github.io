Academic team project

Tutex — multi-level tutoring platform

Role: Backend developerTeam projectNode.js · MongoDB

Finding a qualified tutor, booking sessions and keeping parents informed is usually scattered across messages and word of mouth. Tutex centralizes this for students, parents and teachers across education levels.

  • Authentication

    Per-device JWT sessions, OTP flows and a two-step admin sign-in.

  • Teacher search

    Search with location-aware results.

  • Session booking

    Bookings with parent–child enrollment.

  • Document validation

    Diploma upload with an admin review workflow.

My contribution

  • Designed and built REST APIs with Node.js and Express.
  • Modeled data with MongoDB and Mongoose, including parent–child enrollment relations.
  • Implemented authentication and authorization (JWT, OTP, role checks).
  • Structured business logic for search, booking and document access control.
  • Documented endpoints with Swagger and tested them with Postman.
  • Added security middleware (Helmet, rate limiting, XSS protection) and a 30-day soft-delete flow for accounts.
  • Helped debug deployment issues on Render.

A collaborative university project built by a team; the mobile client was built with React Native by teammates. It is not a commercial product.
