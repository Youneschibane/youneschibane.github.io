About

A student who likes what happens behind the screen

I'm a Computer Science student at ESI Algiers, in the first year of the engineering cycle. Backend development appeals to me because it combines design and rigor: shaping APIs that are clear to use, modeling data so it stays consistent, and protecting access properly.

I've built REST APIs with Node.js, Express and MongoDB, most notably for Tutex, an academic team project where I handled the backend while teammates built the mobile client. Working in a team taught me as much about Git workflows, API documentation and debugging deployments as about code.

I'm drawn to software architecture, security and problem-solving, and I'm currently learning SQL, Docker, Linux and automated testing to build more dependable systems.
