Selected work

Academic team project

Tutex — multi-level tutoring platform

The problem

Finding a qualified tutor, booking sessions and keeping parents informed is usually scattered across messages and word of mouth. Tutex centralizes this for students, parents and teachers across education levels.

What the platform does

  • Accounts for students, parents and teachers, with parents able to enroll and book for their children.
  • Teacher search with location-aware results.
  • Session booking and management.
  • Document upload for teachers, with a diploma validation workflow reviewed by admins.

My contribution (backend)

  • Designed and built REST APIs with Node.js and Express.
  • Modeled data with MongoDB and Mongoose, including the parent–child enrollment relations.
  • Implemented authentication and authorization: JWT sessions per device, OTP-based flows and a two-step admin sign-in.
  • Structured business logic for search, booking and document access control.
  • Documented endpoints with Swagger, tested them with Postman, and helped debug deployment issues on Render.
  • Added security middleware (Helmet, rate limiting, XSS protection) and a soft-delete flow with a 30-day grace period for account deletion.

A collaborative university project built by a team; the mobile client was built with React Native by teammates. It is not a commercial product.
